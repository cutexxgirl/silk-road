# FragmentCamera

NeoForge mod template for Minecraft 1.21.1.

Author: cutexxgirl

FragmentCamera is intended to smooth camera movement in the Minecraft client.

## Development

- Minecraft: 1.21.1
- NeoForge: 21.1.233
- Java: 21

Useful commands:

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```
